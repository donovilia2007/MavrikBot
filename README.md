### Идея

Создание телеграм-бота, который реализует несколько крутых, по мнению автора фич:
- Функционал для проведение Тайного Санты
- Отправление псевдорандомного стикера с котиком на сообщение, содержащего подстроку "мур" или "мяу"
- Функционал для администрирования чатов

Отмечу, что возможны добавления

### Итерация 1

К первой итерации я планирую реализовать функционал для проведения Тайного Санты.
Для этого я воспользуюсь своими навыками и библиотеками _aiogram_, _aiosqlite_

### Итерация 2

Ко второй итерации я планирую реализовать функционал для администрирования чатов, а также отправление псевдорандомного стикера с котиком.
Также в планы входит реализация фичи от ассистента

### Используемые библиотеки

* _aiogram_ - версия 3.27.0
* _aiosqlite_ - версия 0.22.1

### Функционал

[MavrikBot](https://t.me/Mavrik_my_Bot) обрабатывает сообщения, поступаемые ему в личные сообщения.
Однако, если Вы хотите, чтобы бот обрабатывал сообщения в группах, необходимо дать ему админку

##### Про котиков

На любое сообщение, в котором есть подстрока "мур" или "мяу" отправляется псевдорандомный стикер с котиком.
id стикеров прописаны в файле [stickers.txt](./stickers.txt)

##### Про Тайного Санту

Команды, актуальные для групп:

* /santa - открыть запись на игру
* /start_santa - провести жеребьёвку
* /clear_game - очистить информацию о последней игре

Команда актуальная для личных сообщений:

* /where_santa - вывести список всех групп и всех получателей подарков от пользователя

##### Про администрирование

* /mute [_num_ (m | h | d)] - замутить пользователя. По умолчанию мутит на 15 минут в чате.
Можно мутить на определённое количество минут | часов | дней, для этого указывая нужный символ.
* /unmute - размутить пользователя

### Как запустить проект?

Обратите внимание, что проект разрабатывался для Python 3.12.3

Необходимо скачать репозиторий. В локальном репозитории должен находиться файл __TOKEN.txt__, в котором
должен лежать ключ, полученный через __@BotFather__ в Telegram. Затем необходимо скачать зависимости, прописанные в файле [requirements.txt](./requirements.txt).

```
pip3 install -r requirements.txt
```
Запустить проект можно через команду 
```
python3 main.py
```
